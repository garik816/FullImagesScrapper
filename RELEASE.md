# FullImagesScrapper 1.8.0

Release date: 2026-09-07

- Renamed the FreshRSS extension from `F95 Full Images` to `FullImagesScrapper`.
- Keeps existing `f95_full_images_*` preferences for non-breaking upgrades.
- Uses the local Solverr endpoint `http://127.0.0.1:8191/v1` when FreshRSS and Solverr run in the same CT.
- Includes the RuTracker Fastpic original-image resolver from the verified 1.7.1 release.

Release artifact: `releases/FullImagesScrapper-1.8.0.zip`.
